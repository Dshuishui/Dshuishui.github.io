项目经历

服务器无感的强隔离高弹性一致性分布式存储系统 2023.12 — 2026.02

学生小组负责人 · 国家重点研发计划子课题（GOODLAB 课题）

项目描述：针对服务器无感框架下函数级别计算对分布式数据一致性的差异化需求，以及传统一致性方案在性能与可靠性间的权衡问题，实现了融合因果一致性与强一致性的混合分布式存储系统。

技术实现：基于 Raft 算法构建一致性层，基于 CRDTs 支持因果一致性，通过 Gossip 协议维护因果关系；利用 LSTM 神经网络分析节点访问模式，预测最优副本同步策略，实现强一致性与因果一致性的自适应切换。

项目成果：SCI 一区期刊论文 1 篇，发明专利 1 项。

基于 Raft 优化的键值分离分布式存储系统（Nezha） 2024.06 — 至今

独立实现 · 个人科研课题  GitHub

项目描述：针对基于 Raft 的分布式 KV 存储在 LSM-tree 引擎下的写放大问题（每次写操作至少三次磁盘写入），设计并实现原创分布式键值分离存储系统 Nezha。

技术实现：在 Raft 日志处理阶段实现 KV 分离以减少写放大；设计自适应垃圾回收（GC）框架，通过多轮 GC 策略动态平衡读性能损耗，同时实现 GC 版本隔离保证正确性；结合 Raft 日志批量同步和多协程并发处理。

项目成果：已被 ICDE 2026（CCF A 类会议）录用；同时被第 30 届 ACM SIGOPS 中国系统研讨会（ChinaSys'26 Spring）录用，以 Oral 形式汇报。

端云协同驱动的工业产品质量检测系统 2024.05 — 2024.11

学生团队负责人 · 权威企业赛事

项目成果：第十九届"挑战杯"华为云赛道国家级二等奖（队长）。

ScholarScout — AI 驱动的自然语言学术论文搜索工具 2026.04 — 至今

独立开发 · 个人项目  GitHub · Demo

项目描述：面向非 CS 背景科研人员的学术论文检索工具，用户以中文自然语言描述需求（如"找 2023 年以后关于大模型幻觉的论文"），系统自动提取关键词并并发检索 10 个学术数据库（arXiv、Semantic Scholar、PubMed 等），AI 二次过滤相关性，支持一键 PDF 预览与批量下载。

技术实现：前端基于 React 18 + TypeScript + Vite，后端使用 FastAPI + SQLAlchemy，通过 Server-Sent Events（SSE）实现实时进度流式推送；集成 DeepSeek API 进行意图解析与相关性验证；实现多源去重（DOI 匹配 + 标题归一化）、用户注册/收藏/阅读历史等功能；部署于个人云服务器，使用 Nginx + systemd + Umami 统计。

项目成果：开源（MIT 协议），提供在线 Demo，支持 10 个主流学术数据源并发检索。
