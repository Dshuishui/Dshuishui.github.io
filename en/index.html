Projects

Serverless-Transparent High-Isolation Elastic Distributed Storage System Dec 2023 — Feb 2026

Student Group Leader · National Key R&D Program Sub-project (GOODLAB)

Overview: Targeting the heterogeneous consistency requirements of function-level computation under serverless frameworks and the performance-reliability tradeoff of traditional consistency protocols, we designed and implemented a hybrid distributed storage system combining causal and strong consistency.

Implementation: Built a strong-consistency layer on Raft; supported causal consistency via CRDTs with Gossip-based causal tracking. Core innovation: LSTM neural network analyzes node access patterns and network topology to predict the optimal replica synchronization strategy, enabling adaptive switching between strong and causal consistency.

Outcome: 1 SCI Q1 TOP journal paper, 1 invention patent.

Nezha: Raft-Optimized Key-Value Separated Distributed Storage Jun 2024 — Present

Independent Research  GitHub

Overview: Raft-based distributed KV stores suffer from write amplification under LSM-tree engines (at least 3 disk writes per operation). Nezha addresses this by separating keys and values at the Raft log processing stage.

Implementation: Designed an adaptive GC framework with multi-round GC policies to dynamically balance the read-performance overhead introduced by KV separation; implemented GC version isolation to ensure correctness; combined with batched Raft log synchronization and concurrent goroutine processing.

Outcome: Accepted at ICDE 2026 (CCF-A).

Edge-Cloud Collaborative Industrial Quality Inspection System May 2024 — Nov 2024

Team Leader · Enterprise Competition Project

Overview: Addressing accuracy and efficiency bottlenecks in traditional industrial inspection, we designed an intelligent quality inspection solution with edge-cloud computational collaboration.

Implementation: Built on YOLOv8 and Huawei ModelArts; heterogeneous training with Ascend NPU + GPU; edge deployment on development boards and a HarmonyOS APP; combined local edge inference with cloud-side collaborative detection.

Outcome: National 2nd Prize, 19th "Challenge Cup" Huawei Cloud Track (Team Leader).
